WCAG edition, based on VPAT version 2.5.

Product

  • Name and version: Describewright Pro 1.0.13 for WordPress
  • Report date: 9 November 2026
  • Description: A WordPress plugin that drafts audio description for videos in the Media Library. Editors work in a video list and a description editor in the WordPress admin. Visitors get a descriptions track, an "Audio description" button under the player and a described transcript.
  • Contact: hello@karelialabs.com

What was evaluated

  • The screens the plugin adds to the WordPress admin: the video list and the description editor, with generated descriptions.
  • What the plugin adds to the public site: the descriptions track, the "Audio description" button, the spoken and shown descriptions, and the described transcript.
  • WordPress itself, the active theme and the browser's own video controls are outside this report.

Evaluation methods

  • Automated testing with axe-core 4.14.0, using its WCAG 2.0 and 2.1 Level A and AA rules, on each screen with real content.
  • Scripted keyboard testing: tab order, visible focus, switching the "Audio description" button with Enter and Space, and operating the transcript.
  • A layout check at a viewport width of 320 CSS pixels.
  • Inspection of the plugin's code for orientation locks, single-key shortcuts and animation.
  • Test environment: Microsoft Edge 157 on Windows 11, with the current WordPress release on the report date.
  • Not done: testing with screen readers or other assistive technology, testing on mobile devices, and testing by people with disabilities. Criteria that need those methods are marked Not evaluated.

Applicable standard

Web Content Accessibility Guidelines 2.1, Level A and Level AA.

Terms

  • Supports: the product met the criterion in the tests described above.
  • Partially supports: some part of the product did not meet the criterion.
  • Does not support: most of the product did not meet the criterion.
  • Not applicable: the criterion does not apply to the product.
  • Not evaluated: the criterion was not tested.
