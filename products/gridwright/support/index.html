Response times

  • Issues that Atlassian classifies as critical: we aim to reply within 24 hours.
  • Other requests: we aim to reply within 5 business days.

These times apply during Monday to Friday, 09:00 to 17:00 Central European Time.

What to include

A good request lets us answer without asking questions first.

  • The address of your Jira site, the issue key and the name of the table field.
  • Where it happened: on the issue, on the create screen, on a transition screen or in the customer portal.
  • The message shown, for example the problem listed under Fix these before saving or This table field needs attention.
  • What you expected to happen, and what happened instead. A screenshot helps.
  • When it happened, with your time zone.

Please do not send passwords or confidential content. If we need an example, we will ask for it.

Common questions

I cannot find the field type.

A Jira administrator creates table fields in the field settings of Jira with Create new field and the type Table grid (Gridwright), then adds the field to the screens of the project.

The table shows the columns Item, Quantity and Notes.

Those are the columns of a field context that has no setup yet. Open the field, Contexts and default value, Configure, choose the columns or a template, and select Save configuration.

Editing is not available.

Gridwright needs an active licence to edit tables. Tables stay visible without one. A site administrator can start a free trial or subscribe in the Atlassian Marketplace.

A number is marked as an error.

The cell could not be read as a number, for example 16 pcs. Numbers can be typed as 1234.5, 1,234.5 or 1 234,5, with or without the prefix and suffix of the column. The table is not saved while a cell has an error.

The table is too large to save.

A table holds up to 200 rows and about 30,000 characters of data. Very long texts reach the character limit first. Shorten the texts, or split the data over two table fields.

How do I get the table into a spreadsheet?

Choose Copy as CSV…, select all the text, copy it and paste it into the spreadsheet. Issue lists and Jira's own CSV export show a short summary of the table instead.

Can customers edit the table in the portal?

Not in this version. Customers see table fields in the Jira Service Management portal, read-only.

Security issues

If you believe you have found a vulnerability, do not post it publicly. Write to support@karelialabs.com instead. The security page says what to include.
