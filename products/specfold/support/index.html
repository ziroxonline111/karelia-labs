Response times

  • Issues that Atlassian classifies as critical: we aim to reply within 24 hours.
  • Other requests: we aim to reply within 5 business days.

These times apply during Monday to Friday, 09:00 to 17:00 Central European Time.

What to include

A good request lets us answer without asking questions first.

  • The address of your Confluence site and the page with the macro.
  • The format and version of the specification (for example OpenAPI 3.0.3) and whether it is attached or pasted. If you can, a reduced copy of the file that still shows the problem.
  • The message shown by the macro, if any, with its line number.
  • What you expected to happen, and what happened instead. A screenshot helps.
  • When it happened, with your time zone.

Please do not send passwords or confidential content. If we need an example, we will ask for it.

Common questions

The macro says no specification has been chosen.

Open the macro settings and either choose an attached file (A file attached to this page) or choose Text pasted here and paste the specification. Save the macro and publish the page.

My file is not in the list.

Only YAML and JSON attachments of the same page are listed. On a brand-new page that has never been published, publish it first, then edit the macro and choose the file.

I get an error with a line number.

The file is not valid YAML or JSON at that position, or it breaks a rule of the specification. Fix it at the line shown. Specifications with warnings are still displayed, with a banner above them.

References to other files or URLs do not resolve.

The viewer reads one self-contained file. Bundle the references into it first (most API tooling can do that), then attach the bundled file.

Can the viewer load a specification from a URL, or send test requests?

No, by design. Both would need outbound network access, which would mean data leaving Atlassian. Attach the file and update the attachment from your build pipeline instead; the viewer always shows the newest version. cURL examples are provided to copy.

The viewer shows the wrong colours.

It follows the theme of Confluence. Each reader can also switch between automatic, light and dark with the button at the top right of the viewer, and the macro has a colour mode setting.

Security issues

If you believe you have found a vulnerability, do not post it publicly. Write to support@karelialabs.atlassian.net instead. The security page says what to include.
