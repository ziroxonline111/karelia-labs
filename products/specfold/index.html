What it does

Put your API documentation on a Confluence page and keep it current. Attach an OpenAPI 3.0 or 3.1, Swagger 2.0 or AsyncAPI 2 or 3 file (YAML or JSON) to the page, or paste it into the macro. Specfold shows searchable endpoints or channels, models, request and response examples and copy-ready cURL commands.

A broken file gets a readable message with the line number instead of a blank macro. Everything runs on Atlassian: no external servers, no data stored, nothing sent anywhere.

  • A real API reference, inside the page

    Endpoints grouped by tag, a models tab, side navigation, search, and links to a single operation that open the page scrolled to it.

  • OpenAPI, Swagger and AsyncAPI

    OpenAPI 3.0 and 3.1 (webhooks, callbacks), Swagger 2.0, AsyncAPI 2 and 3 (channels, operations, messages, bindings) in one uniform view.

  • Examples you can copy

    The examples from your specification, or sample data generated from the schemas, plus a cURL command for every HTTP operation. Nothing is ever sent from the page.

  • Readable errors instead of a blank macro

    YAML or JSON syntax errors with line, column and a snippet of the source; unresolved references with a "did you mean"; unknown fields; a banner for specifications that are shown despite problems.

  • Compare two versions

    Pick an older file and get a Changes tab: added, removed and changed operations and models, with potentially breaking changes marked.

  • Private by design

    No outbound network access, no storage, no external scripts, fonts or images, and a strict content security policy. The macro reads attachments as the person viewing the page, so Confluence permissions apply.

Runs on Atlassian

Specfold is built only on Atlassian Forge. It makes no calls to outside servers, and your data stays in Atlassian: in Confluence itself and in Forge storage on your site. That makes it eligible for Atlassian's Runs on Atlassian program.

Good to know

  • The specification comes from an attachment on the page or from pasted text, never from a URL. That is what lets the app run entirely on Atlassian.
  • There is no Try it out button, because nothing is ever sent from the page. cURL examples are there to copy instead.
  • External references ($ref to other files or URLs) are not followed. Use one self-contained file. The error message says how to bundle one.
  • Files can be up to 4 MB, pasted text up to 200,000 characters.
  • Readers need a Confluence account with access to the page. Anonymous access is not supported.

Data and security

Specfold stores nothing. It reads one attachment as the person viewing the page and shows it in the browser. It makes no calls to outside servers. The security page lists what is stored, for how long and which permissions are needed. The privacy policy and the EULA are public.
