What it does

Make the documents your team sends out straight from Jira: handover reports, SLA summaries, release notes, protocols, contracts. Write a template in Word with fields such as {issue.key} and {issue.fields.customfield_10010}, upload it once, and generate a Word or PDF file from any issue in two clicks. The file is attached to the issue and ready to download.

Run a template for a whole JQL result in the background, export issues to Excel with the columns you choose, or add a step to a Jira Automation rule. Everything runs on Atlassian, and nothing leaves your Jira site.

  • Your own Word templates

    Build the template in Word, with your layout, logo, header and footer. Add fields for any issue data: summary, status, custom fields (by id or by name), people, dates and numbers in your language, subtasks, comments, work logs, linked issues and status history. Loops, conditions and rich text come along.

  • See the result before you make the document

    Preview tags shows every field of the template with the value it gets for the issue, and marks the ones that found nothing, so a typo or an empty field is caught before the file reaches a customer.

  • Word and PDF in one click

    Generate from the ••• menu of an issue. The file is attached to the issue and can be downloaded from the dialog (a very large file is opened from the attachments of the issue). The PDF is made on Atlassian too, with no external conversion service.

  • Bulk documents in the background

    Run a template for a JQL result: a document per issue, attached to each issue, or one combined report such as release notes for a fix version. Jobs show progress and can be stopped and resumed, and a resumed job does not attach a file twice.

  • Excel export with the columns you choose

    Pick standard and custom fields, change the order and get a clean workbook with a frozen header row, filters, real dates and links to the issues.

  • A Jira Automation action

    Generate document from template creates the document when an issue is transitioned, created or commented. Choose the template by name, the formats, the file name, the language and the values.

Runs on Atlassian

Word and PDF Document Generator is built only on Atlassian Forge. It makes no calls to outside servers, and your data stays in Atlassian: in Jira itself and in Forge storage on your site. That makes it eligible for Atlassian's Runs on Atlassian program.

Good to know

  • The PDF is a clean rendition of the Word file (styles, lists, tables, pictures, links, headers and footers), not a pixel-perfect copy. Text boxes, shapes, footnotes and columns are left out of the PDF; the Word file keeps them.
  • Pictures from issues are not inserted. Pictures in your template are kept.
  • Templates are written in Word. There is no template editor inside Jira.
  • A bulk job handles up to 5,000 issues (1,000 by default).
  • Macro-enabled files, old .doc files, password-protected files, zip bombs and files over 10 MB are refused as templates.
  • Support for your own templates is limited to explaining how the tags and filters work.

Data and security

The Word and PDF Document Generator runs entirely on Atlassian. Issue data is read through the Jira API, made into documents inside Forge and written back to Jira as attachments. It makes no calls to outside servers. The security page lists what is stored, for how long and which permissions are needed. The privacy policy and the EULA are public.
